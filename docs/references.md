# References

The PDFs are not redistributed (copyright) — only the references are listed.

2. Schlatter, M., Ducard, G., Rohr, D., & Onder, C. (2024). **Longitudinal Control of a Tilt-rotor VTOL UAV using Incremental Nonlinear Dynamic Inversion.** *2024 International Conference on Control, Automation and Diagnosis (ICCAD)*, Paris, France. IEEE. https://doi.org/10.1109/ICCAD60883.2024.10553973
